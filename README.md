# ridni.app

Static site for Ridni: home, privacy, terms, support, delete-account. Served by GitHub Pages at https://ridni.app.

Edit the page bodies in `_build/pages/*.html`, then run:

```
python3 _build/build.py
```

and commit the generated `index.html`, `*/index.html` and `404.html`.

Source texts and the owner decisions behind them: Ridni project `handoff/web/`.
